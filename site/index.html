Tạo trong Studio

Từ hình minh họa thành tệp avatar hoàn chỉnh.

Tác tử lập trình (coding agent) chuẩn bị bộ rig và các lớp ảnh. Bạn kiểm tra kết quả và tinh chỉnh từng bộ phận trong trình chỉnh sửa cục bộ.

  1. 01

    Đưa hình minh họa cho tác tử

    Mở Claude Code hoặc Codex trong kho mã và yêu cầu làm theo hướng dẫn cho tác tử (tiếng Anh). Ảnh PNG chính diện có nền trong suốt cho kết quả tốt nhất.

  2. 02

    Kiểm tra chuyển động

    Mở dự án trong Studio. Dùng Thử tư thế để quay đầu và nhắm mắt, rồi chọn kiểu chuyển động miệng ở mục Khớp khẩu hình. Mở Tinh chỉnh để điều chỉnh chi tiết hoặc thử bằng tệp âm thanh.

  3. 03

    Chỉnh sửa bằng cách kéo điểm

    Chọn một bộ phận và kéo các điểm trên ảnh. Bản xem trước cập nhật ngay theo chỉnh sửa của bạn. Nếu đường viền ảnh hưởng tới lớp ảnh đã cắt, bấm Lưu và dựng lại lớp.

  4. 04

    Thêm ảnh vẽ riêng cho biểu cảm sống động hơn

    Yêu cầu ảnh mắt và miệng vẽ riêng trong mục Ảnh biểu cảm vẽ riêng để chớp mắt, nói chuyện và nụ cười thêm tự nhiên. Khi đã ưng ý, chọn Xuất .mavatar để đóng gói rig, các lớp ảnh và ảnh vẽ riêng vào một tệp duy nhất.

Phát trực tiếp

Chuyển động theo khuôn mặt. Đưa thẳng lên stream.

Trang Phát trực tiếp của Studio gửi chuyển động của avatar sang một màn hình riêng để bạn thêm vào OBS.

Theo dõi khuôn mặt hoặc dùng giọng nói

Bật camera và hiệu chuẩn, sau đó điều chỉnh lật gương, độ nhạy và độ mượt. Không bắt buộc có camera: micro vẫn có thể điều khiển khẩu hình trong khi avatar giữ chuyển động nghỉ.

Thêm nguồn Browser vào OBS

Chọn nền, sao chép URL OBS và dán vào Browser Source. Dùng nền trong suốt ngay trong OBS hoặc chọn phông xanh cho Chroma Key trên phần mềm quay màn hình khác.

Cả hai màn hình đều chạy trên máy chủ phát triển cục bộ. Giữ trang Phát trực tiếp mở ở cửa sổ riêng trong lúc stream. Nếu không muốn cài đặt, hãy mở Player để điều khiển tệp .mavatar bằng camera và micro ngay trên trình duyệt rồi ghi vào OBS bằng Window Capture. Hướng dẫn phát trực tiếp (tiếng Anh) ↗

Nhúng với mesh-avatar

Đưa avatar vào canvas ứng dụng của bạn.

Tải tệp bạn đã xuất từ Studio. Runtime sẽ tự động chạy chuyển động, còn ứng dụng của bạn điều khiển tư thế, biểu cảm và âm lượng giọng nói.

  • WebGL
  • ES modules
  • Kiểu TypeScript
  • Không phụ thuộc React

Cài đặt runtime

npm install mesh-avatar

Đặt tệp .mavatar trong thư mục tài nguyên công khai của ứng dụng. Thêm thẻ canvas vào HTML và chạy JavaScript từ module khởi tạo của ứng dụng.

Chuyển động nghỉ và chớp mắt tự động khởi chạy. Khi nói, ứng dụng chỉ cần phát âm thanh và gửi mức âm lượng vào runtime.

API runtime và ví dụ (tiếng Anh) ↗

Thêm canvas HTML

<canvas id="avatar" width="720" height="960"></canvas>

Tải và điều khiển JavaScript

import { loadMeshAvatar } from 'mesh-avatar';

const canvas = document.querySelector('#avatar');
const avatar = await loadMeshAvatar(
  canvas, '/avatars/character.mavatar'
);

// Chọn biểu cảm hoặc đặt tư thế.
avatar.setExpression('smile');
avatar.setParameters({ angleX: 10, gazeX: 0.25 });

// Trong lúc ứng dụng phát âm thanh, gửi độ lớn âm lượng (0–1).
avatar.setSpeaking(true);
avatar.setVoiceLevel(0.6);

// Khi nói xong, đưa nhân vật trở về trạng thái nghỉ.
avatar.setVoiceLevel(0);
avatar.setSpeaking(false);
avatar.setExpression('neutral');
avatar.setParameters({});

// Gọi avatar.destroy() khi gỡ bỏ canvas.

Cách hoạt động của bản xem trước này JavaScript

import { loadMeshAvatar } from 'mesh-avatar';

const canvas = document.querySelector('#avatar');
const avatar = await loadMeshAvatar(canvas, 'miko.mavatar', { padTop: -0.04 });

// Các nút biểu cảm đổi sắc thái khuôn mặt.
for (const button of document.querySelectorAll('[data-expression]')) {
  button.addEventListener('click', () => {
    avatar.setExpression(button.dataset.expression);
  });
}

// Bật/tắt nói thử; bản demo dùng đường cong âm lượng mô phỏng không phát tiếng.
let speaking = false;
document.querySelector('#talk').addEventListener('click', () => {
  speaking = !speaking;
  avatar.setSpeaking(speaking);
  if (!speaking) avatar.setVoiceLevel(0);
});

// Xoay đầu và ánh nhìn về phía con trỏ (x và y nằm trong khoảng -1 đến 1).
const hero = document.querySelector('.hero');
hero.addEventListener('pointermove', (event) => {
  const rect = hero.getBoundingClientRect();
  const x = (event.clientX - rect.left) / rect.width * 2 - 1;
  const y = 1 - (event.clientY - rect.top) / rect.height * 2;
  avatar.setParameters({ angleX: x * 12, angleY: y * 8, gazeX: x * 0.7, gazeY: y * 0.55 });
});
hero.addEventListener('pointerleave', () => avatar.setParameters({}));

// Khi đang nói, gửi mức âm lượng (0–1) ở mỗi khung hình.
function frame(time) {
  if (speaking) avatar.setVoiceLevel(Math.abs(Math.sin(time / 90)));
  requestAnimationFrame(frame);
}
requestAnimationFrame(frame);
